# Health_G

Сайт на **Flask** о **здоровом питании**: статьи-ориентиры, справочник продуктов с карточками по клику и калькулятор ИМТ / суточных калорий (формула Миффлина — Сан Жеора). Интерфейс на **Bootstrap 5**, иконки **Lucide** (подключаются с CDN). Вёрстка адаптивная — для десктопа и телефона.

Материалы носят ознакомительный характер и **не заменяют** консультацию врача или диетолога.

## Страницы

| Адрес | Содержание |
|-------|------------|
| `/` | Главная, вводная информация |
| `/o-pitanii` | Основы питания, FAQ |
| `/produkty` | Список продуктов, по клику — подробности в модальном окне |
| `/kalkulyator` | ИМТ, BMR, TDEE; для возраста 10–17 лет — без взрослых категорий ИМТ и с предупреждениями для детей |

## Требования

- Python 3.10+ (рекомендуется)
- `pip`

## Как запустить

1. Перейдите в папку проекта:

   ```bash
   cd Health_G
   ```

2. Создайте и активируйте виртуальное окружение (по желанию, но удобно):

   **Windows (PowerShell):**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS / Linux:**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

5. Откройте в браузере: **http://127.0.0.1:5000**

Режим `debug=True` включён в `app.py` для разработки: код подхватывается при сохранении, на продакшене его отключают и используют WSGI-сервер (например, Gunicorn).
